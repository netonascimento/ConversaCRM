# Marca Conversa CRM

Logo usado no site (`public/favicon.svg` e o `.brand-mark` das páginas). O nome é escrito em Geist SemiBold, já convertido em curvas nos SVGs (não precisa da fonte instalada).

| Arquivo | Uso |
|---|---|
| `conversacrm-logo.svg` / `-2000.png` | Logo principal, para fundo claro |
| `conversacrm-logo-negativo.svg` / `-2000.png` | Para fundo verde ou escuro |
| `conversacrm-logo-vertical.svg` / `-1200.png` | Versão empilhada (cartão, capa, apresentação) |
| `conversacrm-icone.svg` / `-512.png` / `-1024.png` | Só a marca (app, favicon, avatar) |
| `conversacrm-icone-claro.svg` / `-512.png` | Marca para fundo verde ou escuro |
| `conversacrm-perfil.svg` / `-1080.png` | Foto de perfil (Instagram, WhatsApp, Google), o app corta em círculo |

Cores: verde `#14532d`, creme `#f7f5ef`, verde-claro do ponto `#b9e2c5`, texto `#10231a`.
Não estique, não troque as cores e deixe uma margem livre de pelo menos meia altura do ícone em volta.
